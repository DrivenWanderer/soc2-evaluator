### Remediation Guidance for CFG-002: Verbose Errors and Debug Compilation

**Category:** Configuration
**Default TSC Criteria:** CC6.1 (Data Protection), CC7.2 (Monitoring & Anomaly Detection)

#### Immediate Actions:
1. **Disable Debug Compilation in Production:**
   In `web.config`, ensure `compilation debug="false"` is set for all production deployments.
2. **Enable Custom Error Handling:**
   Ensure `customErrors mode="RemoteOnly"` or `mode="On"` is configured so remote clients never receive raw exception stack traces.
3. **ASP.NET Core DetailedErrors:**
   In ASP.NET Core `appsettings*.json`, ensure `"DetailedErrors"` is set to `false` or excluded from production configs.

#### Configuration Example (web.config):
```xml
<!-- BEFORE (Vulnerable - raw stack traces exposed to remote clients): -->
<configuration>
  <system.web>
    <compilation debug="true" />
    <customErrors mode="Off" />
  </system.web>
</configuration>

<!-- AFTER (Secure - custom errors presented to users, details logged server-side): -->
<configuration>
  <system.web>
    <compilation debug="false" />
    <customErrors mode="RemoteOnly" defaultRedirect="~/Error.html" />
  </system.web>
</configuration>
```

#### ASP.NET Core Example (Program.cs):
```csharp
if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/Error");
    app.UseHsts();
}
```
