### Remediation Guidance for DEP-001: Known-Vulnerable Packages

**Category:** Configuration
**Default TSC Criterion:** CC7.1 (Vulnerability Management & Monitoring)

#### Immediate Actions:
1. **Identify Patched Version:** Review the referenced security advisory (CVE / GHSA) to identify the minimum patched release.
2. **Update Package Reference:**
   - For direct dependencies: Update the package reference in your `.csproj` or `Directory.Packages.props`:
     ```bash
     dotnet add package <PackageName> --version <PatchedVersion>
     ```
   - For transitive dependencies: Explicitly reference the patched version as a direct package dependency or pin the version in central package management (`Directory.Packages.props`).

#### Configuration Example (Project.csproj):
```xml
<!-- BEFORE (Vulnerable release): -->
<PackageReference Include="Newtonsoft.Json" Version="12.0.1" />

<!-- AFTER (Patched release): -->
<PackageReference Include="Newtonsoft.Json" Version="13.0.3" />
```

#### Ongoing Prevention:
- Enable automated dependency updates (e.g., Dependabot or Renovate).
- Incorporate `dotnet list package --vulnerable` or OSV-Scanner as a required pull request gating check.
