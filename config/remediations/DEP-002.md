### Remediation Guidance for DEP-002: Dependency Lockfile Missing or Unpinned

**Category:** Configuration / Build
**Default TSC Criteria:** CC6.6, CC8.1 (Integrity, Change Management & Software Supply Chain)

#### Immediate Actions:
1. **Enable NuGet Lockfiles in .NET:** Enable `RestorePackagesWithLockFile` in your `Directory.Build.props` or project files:
   ```xml
   <PropertyGroup>
     <RestorePackagesWithLockFile>true</RestorePackagesWithLockFile>
     <RestoreLockedMode Condition="'$(CI)' == 'true'">true</RestoreLockedMode>
   </PropertyGroup>
   ```
2. **Generate and Commit the Lockfile:** Run `dotnet restore --use-lock-file` and commit the generated `packages.lock.json` file into source control.
3. **Pin Explicit Version Numbers:** Replace wildcard (`*`, `1.*`) or floating version specifications in `*.csproj` or `package.json` with exact, tested semantic version numbers.
4. **Enforce Locked Mode in CI/CD:** Ensure build pipelines restore with `--locked-mode` (or `npm ci` for Node.js) so builds fail if the lockfile does not match declared dependencies.
