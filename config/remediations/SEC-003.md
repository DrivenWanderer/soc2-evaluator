### Remediation Guidance for SEC-003: Missing Authentication/Authorization on Endpoints

**Category:** Code
**Default TSC Criteria:** CC6.1, CC6.3 (Logical Access & Role-Based Authorization)

#### Immediate Actions:
1. **Audit Exposed Endpoints:** Review all controller actions and minimal API endpoints lacking an explicit `[Authorize]` attribute or `.RequireAuthorization()` call.
2. **Apply Fallback Authorization:** Configure global authorization policies requiring authenticated users by default across all endpoints.
3. **Explicitly Annotate Anonymous Endpoints:** If an endpoint is intentionally public (e.g., login, health check, password reset initiation), explicitly mark it with `[AllowAnonymous]`.

#### Code Example (ASP.NET Core):
```csharp
// BEFORE (Insecure - Controller actions allow anonymous callers by default):
[ApiController]
[Route("api/[controller]")]
public class AccountController : ControllerBase
{
    [HttpGet("profile")]
    public IActionResult GetProfile() => Ok(...);
}

// AFTER (Secure - Explicit authorization required):
[Authorize]
[ApiController]
[Route("api/[controller]")]
public class AccountController : ControllerBase
{
    [HttpGet("profile")]
    public IActionResult GetProfile() => Ok(...);

    [AllowAnonymous]
    [HttpGet("health")]
    public IActionResult Health() => Ok();
}
```
